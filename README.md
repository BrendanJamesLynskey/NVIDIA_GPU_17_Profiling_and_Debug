# Profiling & Debug — Nsight Systems, Nsight Compute, NVTX, CUPTI

The full NVIDIA profiling toolchain — Nsight Systems for system-wide timelines, Nsight Compute for kernel-level analysis, NVTX for annotations, CUPTI for programmatic capture, plus DCGM/nvbandwidth/nvitop for fleet and bandwidth checks. Worked workflows for the common questions ("why is my training slow?", "why is this kernel slow?") and an interactive tool picker.

**Live site:** https://brendanjameslynskey.github.io/NVIDIA_GPU_17_Profiling_and_Debug/

Part of the [NVIDIA GPU Architectures series](https://github.com/BrendanJamesLynskey/LLMs#nvidia-gpu-architectures).
